# 🧮 Simple Calculator

A sleek, responsive, and mobile-friendly web calculator built using **HTML, CSS, and JavaScript**. Optimized for a seamless experience on both PC and mobile devices.

---

## ✨ Features

* **Cross-Platform Design:** Fully responsive layout for desktop browsers and mobile touchscreens.
* **Mobile-Optimized:** Includes haptic touch feedback (vibration) and touch-friendly controls.
* **Clean Interface:** Modern dark-mode UI with clear color-coded buttons.
* **Basic Math Operations:** Supports addition, subtraction, multiplication, and division.

---

## 🛠️ Tech Stack

* **HTML5:** Page structure and layout
* **CSS3:** Responsive grid layout, animations, and dark-theme styling
* **JavaScript (ES6):** Calculation logic and haptic feedback

---

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open the project folder on your computer.
3. Double-click **`index.html`** to run the application in any modern web browser.
